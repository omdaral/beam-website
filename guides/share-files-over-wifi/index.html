How to share files over Wi-Fi without cloud uploads

Beam FileShare turns one computer or Android device into a local file host. Other devices open its link in a browser to upload or download files over the same network. The transfer does not use cloud storage.

What you need

Install Beam FileShare on the device that will host the files. Connect the host and the devices joining it to a trusted local Wi-Fi network that allows devices to communicate with one another. Internet access is not needed for a transfer after Beam is installed.

Some guest Wi-Fi networks enable client isolation, which prevents connected devices from reaching each other. Use a network that allows local-device connections if the link cannot be opened.

Start a local file transfer

  1. Download and start Beam FileShare on the device containing the files. The desktop app and Android app can act as the host.
  2. Connect the other devices to the same Wi-Fi network. If the network blocks local connections, switch to a trusted network or use Beam's hotspot mode where available.
  3. Open the shared local address shown by Beam, or scan its QR code, from another device's browser. The page lets connected users upload or download files without installing Beam on the receiving device.

Know who can access the shared folder

Beam FileShare moves files across your local network; it does not upload them to a cloud-storage service. By default, the shared page does not require separate accounts or passwords. Anyone who can reach it may upload, download, and delete shared files, so use a network you trust and share only files you intend to make available.

Local transfers use HTTP by default. Beam also provides an optional TLS mode; when enabled, follow the app's fingerprint guidance for its self-signed certificate.

If the other device cannot connect

  • Confirm both devices are on the same Wi-Fi network and can communicate locally; a guest network may block this.
  • On the host, allow Beam through the operating-system firewall for a private or trusted network.
  • Reopen the current address or scan a fresh QR code shown by the host.

Phones and tablets can join from a browser

Android, iPhone, and iPad can open the host's link in a browser. The receiving device does not need the Beam app; install the Android app only when you want the Android device itself to host files.

Good to know

Does local Wi-Fi file sharing need internet?

No. Once Beam FileShare is installed, transfers work over a local network that lets the devices communicate. Internet is needed to download Beam or check for updates.

Do receivers need to install Beam?

No. Receivers open the host's link in a browser. Install Beam only on the device hosting the shared folder.
