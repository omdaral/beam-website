Why Beam?

Built for the local network: fast, simple, works offline.

No install

Copy the folder anywhere and double-click. No Python, no admin rights.

Huge files, no limits

Parallel small chunks with a checksum per chunk, auto-resume on drop.

Works offline

Embedded Arabic font and local QR codes. Everything stays on your network.

Arabic / English

Language button for everyone; the host sets the default visitor language.

One clear folder

Everything shared lives in Downloads/Beam. Copy there to publish instantly.

Network security

The Wi-Fi password is the only access control. Auto-stops after 5 idle hours.

Share files over Wi-Fi with no internet needed

Beam moves files between your phone and computer on the local network: direct downloads for Linux, Windows, macOS and Android from GitHub Releases — no install, no accounts, no cloud uploads. Your files never leave your network.

Verify your download

Every release ships SHA256SUMS and MANIFEST.json. Compare the hash before running.

sha256sum Beam-*.tar.gz

Compare the output with SHA256SUMS on the release page. A 404 means the repo is still private or the tag was never pushed.

FAQ

Which file? amd64 or arm64?

Run uname -m: x86_64 means amd64, aarch64/arm64 means arm64. Or use the one-liner above — it detects automatically.

Icon does nothing on Linux?

Run ./install.sh inside the folder, then right-click the icon → Allow Launching. Or launch the Beam binary directly.

Do I need an account or internet?

No. Everyone on the same Wi-Fi opens the link and starts sharing. The only security is the network password.
