Transfer files between Android and Windows over Wi-Fi

With Beam FileShare, either an Android phone or a Windows PC can host the shared files. The other device joins through a browser on the same local Wi-Fi network, so the files do not need to be uploaded to cloud storage.

Choose which device will host the files

If the files are on Windows, download and run the Windows build. If the files are on Android, install Beam's Android APK and start the host from the app. In both cases, the other device can join from its browser without installing Beam.

Windows hosts the files; Android joins

  1. Install and start Beam FileShare on the Windows PC. Keep the files in Beam's shared folder.
  2. Connect the Android phone to the same Wi-Fi network as the PC.
  3. Scan the QR code on the Windows screen with the phone camera, or open the displayed local address in the phone's browser.
  4. Use the shared page to download files to Android or upload files from the phone to the host.

Android hosts the files; Windows joins

  1. Install Beam FileShare on Android from the project's Releases page and start the server in the app.
  2. Connect Windows to the same Wi-Fi network. Open the address or QR link shown by Beam in a Windows browser.
  3. Use the browser page to download files from the Android host or upload files from Windows.

Fix common connection problems

  • Both devices must be on a network that allows local traffic. Guest Wi-Fi or client isolation can block the connection even when both devices show Wi-Fi access.
  • If Windows asks about the firewall, allow Beam on a private or trusted network.
  • Check that you opened the current local address from the running host. A local address is only reachable while the host is running and the devices can reach the same network.

Use a trusted network

The shared page is available to devices that can reach the host on the network. By default, there are no separate receiver accounts or passwords, and visitors can upload, download, and delete shared files. Use a trusted Wi-Fi network and stop Beam when you finish.

Good to know

Does Beam FileShare work from Android to Windows without internet?

Yes, if both devices can communicate over the same local Wi-Fi network. Internet is not used to carry the file transfer.

Does Beam need to be installed on both devices?

No. Run Beam on the host only. The other device opens the shared link in a browser.
