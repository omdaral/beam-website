Good to know

Do both devices need Beam installed?

No. Install or run Beam only on the device hosting the shared folder. Other devices join using a web browser.

Does Beam need an internet connection?

File transfers work over a local Wi‑Fi network without internet. Internet access is needed to download Beam or check GitHub for a new release.

Which download should I choose?

Choose the file that matches the device running Beam. Most Windows PCs use Windows 64-bit; most Intel or AMD Linux computers use Linux 64-bit; most newer Macs use Apple Silicon.

Are my files uploaded to the cloud?

Beam is designed to transfer files across your local network. It does not use a cloud storage service for transfers.

Can I use Beam on an iPhone?

An iPhone can join from Safari as the receiving device. You do not need to install a separate app to download or upload through the shared link.
